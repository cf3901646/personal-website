# 视觉原型图详解：创世者的数字圣殿

> 本文档汇集五幕长镜头的关键设计原型图与落地开发细节。所有原型图均存档于 [`assets/designs/`](../assets/designs/)。

---

## 幕 I · 创世 (Genesis)

![创世开场](../assets/designs/01_hero_genesis.jpg)

### 交互实现要点
- **初始态**：页面加载时 `body` 处于纯黑背景（`#000000`），文字全透明。
- **开屏序列**：
  1. `t = 0.0s`: 屏幕中央 `canvas` 出现一个 2px 大小的亮白光核。
  2. `t = 0.5s`: 光核水平横向拉伸为一条微光裂隙（细线）。
  3. `t = 1.0s`: 创作者名字/代号自微光裂隙中升腾浮现，字体附带 `text-shadow: 0 0 20px rgba(255,255,255,0.8)`。
  4. `t = 1.8s`: 下方宣言文字“设计是秩序。代码是意志。”以打字机阻尼逐字显现。
  5. `t = 2.4s`: 背景光漫反射扩散，暗黑背景逐渐退晕，过渡为纯净亮白（`#FAFAFA`），文字由白转为深灰黑（`#1A1A1A`）。

## 幕 II · 造物 (Creations)

![造物作品集](../assets/designs/02_portfolio_creations.jpg)

### 交互实现要点
- **左侧时间刻度**：固定定位的极细垂直标尺（`width: 1px; background: rgba(0,0,0,0.1)`），随着滚动动态点亮当前年份节点。
- **错落浮岛卡片**：
  - 各卡片在 Grid 布局中故意错开垂直对其线，产生呼吸落差感。
  - 卡片集成鼠标悬停 3D Tilt 视差反馈（使用 `transform: perspective(1000px) rotateX(...) rotateY(...)`）。
  - 卡片边框采用高精度微阴影：`box-shadow: 0 20px 40px -15px rgba(0,0,0,0.05)`。
- **原地宇宙展开 (FLIP Animation)**：
  - 点击卡片时，使用 GSAP Flip 插件将卡片平滑过渡扩展至视口 90% 宽度，并就地加载详细 Case Study，避免生硬页面跳转。

## 幕 III · 箴言 (Proverbs)

![箴言博客](../assets/designs/03_blog_proverbs.jpg)

### 交互实现要点
- **背景色变温**：通过 `ScrollTrigger` 监听滚动进度，将根背景色从 `#FAFAFA` 插值渐变到 `#F5F5F0`。
- **书法/宋体标题**：章节名“箴言”采用高质量思源宋体，形成人文思辨的质感。
- **卡片阶梯入场**：每张文章卡片自屏幕底部 `translateY(40px)`，透明度从 0 渐变至 1，按次序交错 0.08 秒浮现。

## 幕 IV · 本相 (Essence)

![本相关于](../assets/designs/04_about_true_form.jpg)

### 交互实现要点
- **全屏暗黑反差**：页面背景瞬间沉降为深邃的 `#0A0A0A`，文字转为纯白。
- **铭文渐显**：诗性短句随滚动条位置，逐行由半透明变为 100% 亮白。
- **技能星座图谱 (Interactive Skill Constellation)**：
  - 基于 Canvas 2D 或 Three.js 绘制节点与动态连线。
  - 节点根据权重拥有不同光晕半径。
  - 鼠标在区域内移动时，光标产生引力场，临近节点轻微向光标漂移并高亮关联线。

## 幕 V · 通道 (Portal)

![通道联系](../assets/designs/05_contact_portal.jpg)

### 交互实现要点
- **背景重归纯粹**：由深黑平滑淡出，重归宁静近白。
- **一键复制微交互**：点击邮箱地址，触发微小震动动画，并在鼠标右上角浮现微缩气泡提示“已铭刻至剪贴板”。
- **流线余韵**：背景中使用低透明度（`opacity: 0.08`）贝塞尔曲线网，模拟量子场或思维连接线缓缓波动。
