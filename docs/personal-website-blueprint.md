## 一、 核心定位与设计哲学

1. **综合型“数字花园”＋作品集**：
   - 既能沉淀 AI / Agent 探索思考与折腾笔记，又能展示代表项目与开源工具，长期积累个人品牌。
2. **反差感美学（Warm Archival Paper & Blind Letterpress）**：
   - 拒绝千篇一律的黑客终端风或冷冰冰的 SaaS 卡片风。
   - 全站以**厚实暖棉纸 + 午后斜阳斑驳树影（Gobo Light）+ 活字凹印（Letterpress Deboss）**为统一视觉语言，传递“技术锋利、表达温润”的独特质感。
3. **纯静态、零负担（100% Static & Markdown-Driven）**：
   - 作品集采用「精美图文卡片 ＋ 深度复盘」模式，点击跳往 GitHub 仓库或站内复盘文章。
   - 本地编写 `.md` 文件，`git push` 自动构建上线，无数据库、无服务器维护心智负担。

## 三、 页面与信息架构

### 1. 第一页：首屏留白序幕（已完成原型 `index.html`）
- **极简构图**：全屏不设传统顶部导航栏与多余口号，大面积暖棉纸留白，正中央仅拓印 **`cf3901646@gmail.com`**。
- **四重环境特效**：
  1. **SVG 亚麻纸张纤维层**：`feTurbulence` 生成细腻的纸张肌理。
  2. **午后斜阳与斑驳树影层**：`-32deg` 暖金光束配合窗外枝叶/百叶窗 Gobo 柔光滤镜，随微风缓慢呼吸摇曳。
  3. **丁达尔金色浮尘（Canvas）**：微米级金色尘埃粒子在对角线阳光带内缓缓漂浮闪烁。
  4. **光标光学视差与一键拓印**：移动鼠标时，阳光偏移与文字凹印阴影/高光角度实时联动；点击文字即可复制邮箱并浮现活字拓印提示。

### 2. 第二页（滚动展开）：个人序言与造物展厅（Selected Projects）
- **风格延续**：背景承接第一屏的暖棉纸与柔和侧光，分割线采用 1px 凹印压槽（`border-top: 1px solid rgba(140,127,106,0.22); box-shadow: 0 1px 0 rgba(255,251,242,0.8)`）。
- **项目卡片**：采用厚卡纸凸起/凹印边框，展示代表作（如 `EasyCV`、`AI Coding Arena`、`Cognitive Assessment`、`Antigravity Agent Rules` 等），提供 `[GitHub 仓库]` 与 `[站内深度复盘]` 双出口。

### 3. 第三页：数字花园（Writing & Notes）
- 暂不锁死繁琐分类，按时间流呈现 AI / Agent 实践笔记与项目复盘，辅以轻量凹印标签。
