# 个人网站蓝图：创世者的数字圣殿

> **定位**：设计师 × 全栈开发者的极简沉浸式单页作品集  
> **基调**：纯净留白为底，精致动画为魂，宏大叙事为骨  
> **语言**：中文  

---

## 一、核心设计哲学

### "Less is Divine"

这不是一个“关于我”的常规求职站，而是一座**数字圣殿**——访客进入的不是一份格式化简历，而是一个创造者的宇宙。

**三大设计原则**：

| 原则 | 解读 | 表现 |
| :--- | :--- | :--- |
| **虚空生万物** | 极致留白不是空，是等待被填充的可能性 | 大面积留白、呼吸感节奏、元素自虚空中浮现 |
| **克制即力量** | 越少的元素越需要精确，每一帧都是刻意为之 | 精密的微动画、丝般的缓动曲线、零冗余装饰 |
| **不言而威** | 不直白宣称“技术卓越”，而让体验与作品自证 | 让交互体验本身证明能力、作品深度自己说话 |

---

## 二、页面叙事结构（单页滚动 · 五幕剧）

整个网站像一部五幕长镜头影片，每幕由滚动驱动推进，层层递进。

### 幕 I：创世（Hero / 开场）

> *“太初有光。”*

**视觉与交互**：
- 页面初次加载时，屏幕全黑 → 一个极细的光点从中心缓慢绽放。
- 光点横向拉伸为一条微光水平线，线化为文字——创作者的代号或名字。
- 名字下方以打字机节奏浮现一句“神谕”式短语（非自我介绍，而是宣言）：
  - 示例：*“设计是秩序。代码是意志。”*
  - 示例：*“万物皆可被创造。”*
- 背景自中心微光渐变扩展为纯净的近白（`#FAFAFA`），光的余韵化为背景中的微弱弥散。
- 极细小的向下呼吸指示器，暗示受众向下翻动探寻。

**设计要点**：
- 开屏无顶栏导航——滚动开始后导航以极低透明度浮动在边缘。
- 加载动画与首帧无缝咬合，杜绝生硬闪烁。
- 字体采用高级无衬线体（Inter、思源黑体）或几何构型字体。

---

### 幕 II：造物（作品集 / Portfolio）

> *“诸界由此而生。”*

**视觉与交互**：
- 滚动触发：左侧浮现细如发丝的垂直时间刻度，右侧展开广袤的造物空间。
- 每个作品是一个“世界”——以高精度缩略图/交互视界为主体，辅以极克制的题记。
- 作品卡片采用**错落浮岛式布局 (Staggered Islands)**：
  - 向下滚动时，不同作品以微妙的时间差从不同景深轻缓浮现。
  - 每个浮岛具备视差深度（Parallax Depth），鼠标移动产生 3D 悬浮倾斜（Tilt Effect）。
  - 点击作品不作外跳路由，而是**原地激活该作品的微宇宙**：其余浮岛柔和淡出，当前卡片展开为全屏 Case Study 深度解析（挑战 → 哲学 → 架构 → 交互演示）。
  - 右上角提供“归还世界”收起动效。

**作品分类机制**：
- 摒弃陈旧的 Tag 标签栏筛选，采用**星系轨道隐喻**：设计作品以圆润柔和的边界呈现，工程架构作品以犀利的几何直线律动表达。

---

### 幕 III：箴言（博客 / 思想）

> *“文字是思想凝固的形态。”*

**视觉与交互**：
- 滚动至此章节，背景色自纯白温和过渡至温润暖灰（`#F5F5F0`），标记叙事篇章的换气。
- 博客篇目以**立体卡片流**呈现：
  - 卡片包含：标题、精炼导言、纪年刻度、分类元数据。
  - 滚动进入视口时，卡片采用阶梯递进（Stagger Animation）自下而上轻浮。
  - 悬停产生微妙抬升，卡片边沿呈现若隐若现的高光反射。
- 首页精选 5 至 8 篇深度沉思，末端以“阅尽卷帙 →”导引至完整归档。

---

### 幕 IV：本相（关于 / About）

> *“凝视深渊者，终将成为深渊本身。”*

**视觉与交互**：
- 全页面最具戏剧冲击力的**深黑反转区域**（`#0A0A0A`）。
- **文字铭刻**：白字以石刻碑文般的庄严感居中排布，随滚动逐行自透明点亮：
  ```text
  我创造界面。
  我编写逻辑。
  我赋予像素以秩序，
  赋予数据以形态。

  设计是我观察世界的透镜。
  代码是我改造世界的工具。
  ```
- **技能星图 (Skill Constellation)**：
  - 铭文下方延展出一副可交互的星座图谱。
  - 每一个星点代表一项核心技艺（如 WebGL、TypeScript、Design Systems、Architecture），相关联的技能由动态细微的光线连通。
  - 鼠标移近星点，星环产生呼吸律动，并浮现该领域的造诣与心得。

---

### 幕 V：通道（联系 / Contact）

> *“若你也是创造者，让我们的世界相遇。”*

**视觉与交互**：
- 背景重新回归近白，戏剧张力收归宁静。
- 极度空旷的留白中，仅保留一句核心邀约与显赫的交互邮箱地址（点击触发平滑复制并在光标旁呈现反馈）。
- 社交矩阵（GitHub、X、Dribbble 等）以极简单色 Icon 横向等距排列。
- 底部页脚附带一行深思彩蛋：“以代码铸造”。

## 三、动效与微交互系统

| 动画维度 | 视觉特征 | 技术实现参数 |
| :--- | :--- | :--- |
| **入场动效** | 渐显 + 沿 Y 轴微量位移，丝滑阻尼 | `cubic-bezier(0.16, 1, 0.3, 1)`，时长 0.8 至 1.2s，交错间隔 0.1s |
| **视差位移** | 前景卡片比背景移速快 15% 至 30% | GSAP `ScrollTrigger.create({ scrub: 1 })` |
| **卡片悬停** | 3D 透视倾斜 + 动态高光散射 | Vanilla-tilt 或 CSS `transform: perspective(...)` |
| **主题过渡** | 背景色随滚动进度插值平滑渐变 | CSS `mix-blend-mode` 或 WebGL 全屏着色器过度 |
| **拟物光标** | 自定义动态圆点，悬浮可点击物体时膨胀吸附 | Canvas 光标监听引擎 |

## 四、色彩与排版规范

### 色彩系统

```css
:root {
  --bg-primary: #FAFAFA;     /* 主基底：纯净近白 */
  --bg-warm: #F5F5F0;        /* 箴言章节：温润暖灰 */
  --bg-abyss: #0A0A0A;       /* 本相章节：戏剧深黑 */
  --text-main: #1A1A1A;      /* 正文字体：高反差深灰黑 */
  --text-muted: #8A8A8A;     /* 辅助说明：中性灰 */
  --accent-gold: #C9A96E;    /* 点缀灵光：微奢暖金（可选） */
  --border-subtle: rgba(0, 0, 0, 0.06);
}
```

### 排版参数

- **正文字号**：`16px` 至 `18px`，中文字体行高不低于 `1.8`，确保纯粹阅读舒适度。
- **标题体系**：`clamp(2.5rem, 6vw, 5rem)`，字重采用 Bold / Heavy，并增加微量字距（`letter-spacing: -0.02em`）。
- **字体组合**：正文使用 `Noto Sans SC`（思源黑体），大标题或文人引言使用 `Noto Serif SC`（思源宋体），技术标量采用 `JetBrains Mono`。

## 五、彩蛋与沉浸细节

1. **时间潮汐感知**：网站根据访客所在时区的实际时间，深夜访问时初始色彩轻微变深，问候宣言微调。
2. **开发者控制台留印**：DevTools 打开时，Console 打印 ASCII 徽章与密友邀请信。
3. **Konami Code 宇宙**：在任意页面键盘键入 `↑ ↑ ↓ ↓ ← → ← → B A`，全屏星空粒子解冻并允许用光标操纵引力场。
